# Руководство пользователя Ak Shumkar VM

## 1. Введение
**Ak Shumkar VM** — это профессиональная платформа для сканирования уязвимостей, построенная на базе Greenbone Community Edition с глубокими модификациями ядра (patched gvmd) и поддержкой композитных сканеров. Платформа объединяет возможности традиционного сканирования (OpenVAS) и анализа по CVE.

## 2. Быстрый запуск
Самый простой способ запустить весь стек (база данных, менеджер, сканеры, веб-интерфейс) — использовать скрипт `start.sh`.

```bash
cd ak-shumkar-VM
./start.sh
```

**Что произойдет:**
- Автоматически соберется фронтенд (GSA).
- Запустятся Docker-контейнеры.
- По умолчанию включится режим `USE_PATCHED_GVMD=1` (поддержка комбинированных сканеров).

После запуска интерфейс будет доступен по адресу: **http://localhost:9393**

---

## 3. Варианты и параметры запуска

### 3.1 Использование `scannerctl.sh`
Для более гибкого управления используйте `scannerctl.sh`. Это основной инструмент администратора.

*   **Развертывание (аналог start.sh):**
    ```bash
    ./scannerctl.sh deploy
    ```
*   **Остановка системы:**
    ```bash
    ./scannerctl.sh stop
    ```
*   **Просмотр логов:**
    ```bash
    ./scannerctl.sh logs -f
    ```
*   **Полная пересборка (с очисткой кэша):**
    ```bash
    ./scannerctl.sh rebuild
    ```

### 3.2 Переменные окружения
Вы можете изменять поведение системы через переменные:

| Переменная | Значение по умолчанию | Описание |
| :--- | :--- | :--- |
| `USE_PATCHED_GVMD` | `1` | `1` — использовать пропатченный gvmd (композитные сканеры). `0` — стандартный режим. |
| `COMPOSE_PROJECT_NAME` | `greenbone-community-edition` | Имя проекта в Docker. |

**Пример запуска в стандартном режиме (без патчей):**
```bash
USE_PATCHED_GVMD=0 ./start.sh
```

## 4. Настройка сканирования (Web UI)

### 4.1 Первичный вход
- **Адрес:** `http://localhost:9393`
- **Логин/Пароль:** По умолчанию используются стандартные учетные записи администратора GVM (обычно `admin` / `admin`, если не были изменены при инициализации БД).

### 4.2 Создание цели (Target)
1. Перейдите в **Configuration** -> **Targets**.
2. Нажмите иконку **New Target** (звездочка).
3. Введите IP-адрес или доменное имя цели в поле **Hosts**.
4. Сохраните.

### 4.3 Запуск задачи (Task)
1. Перейдите в **Scans** -> **Tasks**.
2. Нажмите **New Task**.
3. Выберите созданную ранее **Target**.
4. В поле **Scanner** выберите нужный тип (по умолчанию используется OpenVAS/Patched).
5. Нажмите **Save**, а затем иконку **Play** для запуска.

---

## 5. Особенности "Patched" режима (Композитный сканер)
При работе в режиме `USE_PATCHED_GVMD=1` вам доступны новые типы сканеров:
- **Тип 11/12**: Специальные режимы, позволяющие gvmd одновременно опрашивать данные CVE и запускать активные тесты OpenVAS. Это значительно повышает точность обнаружения уязвимостей.

---

## 6. Диагностика и решение проблем

### 6.1 Просмотр логов контейнеров
Если система не запускается или работает некорректно, проверьте логи:
```bash
./scannerctl.sh logs gvmd      # Логи менеджера
./scannerctl.sh logs openvas   # Логи сканера
./scannerctl.sh logs gsa       # Логи веб-интерфейса
```

### 6.2 Очистка зависших процессов
В случае некорректной остановки могут остаться lock-файлы БД:
```bash
# Скрипт start.sh делает это автоматически, но можно и вручную:
sudo rm -f /tmp/.s.PGSQL.5432.lock
```

### 6.3 Обновление фидов (NVT/SCAP/CERT)
Данные об уязвимостях обновляются автоматически при запуске контейнеров `*-data`, но вы можете инициировать синхронизацию вручную через UI в разделе **Administration** -> **Feed Status**.
