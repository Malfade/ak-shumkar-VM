## 3. Методология сканеров

### 3.1 OpenVAS (Greenbone)

| Аспект                       | Описание                                                                    |
|------------------------------|-----------------------------------------------------------------------------|
| **Подход**                   | Network-based + Authenticated (SSH) OS-level scan                          |
| **Фокус**                    | Уровень ОС: пакеты Debian, патчи ядра, сетевые конфигурации               |
| **Метод определения**        | Сравнение версий пакетов с DSA (Debian Security Advisories)                |
| **Сильные стороны**          | Точное выявление патчей ОС; детальный анализ TLS/SSL и cookie              |
| **Слабые стороны**           | Не проверяет прикладные уязвимости (Tomcat, JRE) на глубоком уровне       |
| **CVSS версия**              | CVSS v3.1                                                                   |

### 3.2 Rapid7 (InsightVM)

| Аспект                       | Описание                                                                    |
|------------------------------|-----------------------------------------------------------------------------|
| **Подход**                   | Network-based + Authenticated (Unix) + Application-level scan              |
| **Фокус**                    | Прикладной уровень: Apache Tomcat, JRE, Elasticsearch, Unix-аудит         |
| **Метод определения**        | Fingerprinting версий + CVE-check + Unix policy audit                      |
| **Сильные стороны**          | Широкий охват middleware, Java-стека, прав файловой системы                |
| **Слабые стороны**           | Менее детальный анализ конкретных конфигураций TLS/Cookie                  |
| **CVSS версия**              | CVSS v3.x                                                                   |

## 10. Механизм группировки уязвимостей OpenVAS

OpenVAS использует принципиально иной способ представления уязвимостей по сравнению с Rapid7. Это напрямую влияет на интерпретацию разницы в счётчиках (18 vs 129) и является ключевым для понимания реального покрытия.

### 10.1 Принцип: одна запись DSA = один `apt upgrade` = N CVE

OpenVAS группирует уязвимости по **Debian Security Advisories (DSA)**. Каждая DSA-запись соответствует одному пакету, который нужно обновить, но может закрывать десятки CVE одновременно.

> [!IMPORTANT]
> OpenVAS показывает 18 находок, но каждая находка — это потенциально группа из 1 до 40+ CVE. Обновление одного пакета закрывает всю группу целиком. Rapid7 считает каждый CVE отдельной находкой, отсюда 129 записей.

### 10.3 Эффективность: сколько CVE закрывает каждая команда

```bash
# Одна команда — десятки CVE:
apt-get upgrade linux-image-amd64   # закрывает 40+ CVE ядра
apt-get upgrade libnss3             # закрывает группу CVE NSS
apt-get upgrade bind9               # закрывает 3+ CVE DNS

# Полный набор команд для закрытия всех OpenVAS-находок на уровне ОС:
apt-get update && apt-get upgrade -y \
  linux-image-amd64 \
  libnss3 libxml-parser-perl \
  bind9 bind9-libs bind9-dnsutils \
  curl libcurl4 libcurl3-gnutls \
  libpng16-16 python3-urllib3 \
  libc6 libssh2-1 libkrb5-3 \
  sudo nginx libgnutls30 postgresql-15
```

### 10.4 Что это означает для сравнения с Rapid7

| Вопрос | Ответ |
|---|---|
| Почему у Rapid7 129 находок, а у OpenVAS 18? | Rapid7 считает каждый CVE отдельной записью; OpenVAS группирует по DSA |
| Перекрываются ли находки? | Да — большинство Critical из Rapid7 (ядро, libnss3, bind9, curl) закрываются теми же `apt upgrade` что и в OpenVAS |
| Что OpenVAS реально "не нашёл"? | Только то, что находится вне области ОС-пакетов: Tomcat, JRE, Elasticsearch, Unix-аудит файловой системы |
| Если выполнить план OpenVAS, сколько Rapid7-находок закроется? | Обновление ОС-пакетов по плану OpenVAS закрывает ~60–70% от 129 находок Rapid7 |

## 11. Ключевые выводы

> [!NOTE]
> OpenVAS детально анализирует конфигурацию SSL/TLS (SHA-1, DH-группы, cipher suites), атрибуты HTTP-cookies и hardware-уязвимости (MMIO/Spectre) — то, что Rapid7 не охватывает.

> [!NOTE]
> Rapid7 значительно полнее покрывает прикладной уровень: Apache Tomcat, JRE, Elasticsearch, а также Unix-аудит прав файловой системы — области, слабо охваченные OpenVAS.

> [!CAUTION]
> **Оба сканера обязательны.** OpenVAS и Rapid7 дополняют друг друга и не могут полноценно заменить один другого. Особенно критично то, что RCE-уязвимости в Apache Tomcat (CVE-2025-24813, CVE-2025-55752, CVSS 9.8) были обнаружены исключительно Rapid7 и полностью пропущены OpenVAS. Использование только одного инструмента создаёт критические слепые зоны в безопасности.
